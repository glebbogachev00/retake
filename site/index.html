Made because I was tired of recording the same demo again

I built Retake for my own launches and client walkthroughs, and I use it most days. The three products above are the proof so far.

Give Retake to your coding agent

Paste this inside your app project. The agent installs Retake and opens its local first-run flow.

Set up Retake from https://github.com/glebbogachev00/retake in this project and open its local UI. Let the first-run questions collect the app URL, workflow, and sound preference; use those answers instead of asking me twice. Dry-run the workflow, record a silent preview, and show it in the Retake UI. Wait for my review, then apply my corrections and rerun it. Add voiceover only after I approve both the recording and narration script. Tell me where the finished MP4 is. Do not deploy, commit, or ask me to paste secrets into chat.

Or install it yourself:

npm install -g retake-demos
mkdir demos && cd demos && retake install
