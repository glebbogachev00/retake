How it works

You provide intent. The agent writes the flow. Retake verifies, records, and renders it.

You ask

"Record a demo of checkout." That sentence is the brief for the agent you already use.

Your agent builds and checks the flow

It reads your app, writes a small YAML demo, and dry-runs every selector and wait. Nothing records until the walkthrough works.

Retake records the real interaction

Real typing, real clicks, real waits. The result is demo.mp4, a still for each scene, and a proof log of what happened.

You revise without starting over

Change captions, zoom, layout, or format in seconds. When the UI changes, rerun the same flow instead of recording by hand.

What people record

One engine, different audiences. Because the demo is a file, each version is a rerun, not a fresh recording session.

Client walkthroughs

Show the flow they asked about without booking a call. When the question changes, adjust the file and send a fresh take.

Launches and social

Render the same interaction as landscape, square, or vertical. Ship the feature, then post the 20 seconds that show it.

Docs and onboarding

README GIFs, first-run walkthroughs, and help-page clips can be regenerated when the UI changes.

Regression proof

The dry run walks every step in seconds. A demo that fails when your app breaks is both a visible repro and a useful check.

What's in the box

Everything required to produce the same clean take again.

Scenes with captions

Captions are timed from the actual run and placed outside the product frame.

Render-time camera

Zoom and framing applied after recording. Change your mind in seconds, no browser involved.

Presets that post well

1080p landscape, square, vertical, docs GIF. Pick the publishing format, not the browser window.

A still for every scene

Each scene yields a crisp PNG. A video usually ships with a picture next to it.

Secrets stay secret

Credentials live in .env, redacted from logs, warned about if they'd appear on camera.

Stubs and seeds

Stub the backend and reset state so demos stay repeatable.
