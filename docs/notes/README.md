# Working notes

Notes written while building and using Retake: friction found while
recording real demos, audits, plans for branches, and briefs. They are kept
because the reasoning behind a decision is often more useful than the
decision itself.

They are a record, not documentation. Each describes Retake as it was on the
day it was written, may mention commands or files that have since changed or
gone, and is not kept up to date. For how Retake works today, read the
[README](../../README.md), [AGENTS.md](../../AGENTS.md) and the guides in
[docs/](../).
